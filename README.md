# 👻 وحدة الأمان Ghost
**أداة تقوية الأمان لأنظمة Windows و Azure باستخدام PowerShell**

> **تقوية أمنية استباقية لنقاط نهاية Windows وبيئات Azure.** Ghost يوفر وظائف تقوية مبنية على PowerShell يمكنها المساعدة في تقليل متجهات الهجوم الشائعة عبر تعطيل الخدمات والبروتوكولات غير الضرورية.

## ⚠️ إخلاء مسؤولية مهم

**الاختبار مطلوب**: اختبر Ghost دائماً في بيئات غير الإنتاج أولاً. تعطيل الخدمات قد يؤثر على وظائف العمل المشروعة.

**لا ضمانات**: بينما Ghost يستهدف متجهات الهجوم الشائعة، لا يمكن لأي أداة أمان منع جميع الهجمات. هذا مكون واحد من استراتيجية أمان شاملة.

**التأثير التشغيلي**: بعض الوظائف قد تؤثر على وظائف النظام. راجع كل إعداد بعناية قبل النشر.

**التقييم المهني**: لبيئات الإنتاج، استشر مع متخصصي الأمان لضمان توافق الإعدادات مع احتياجات مؤسستك.

## 📊 المشهد الأمني

وصلت أضرار Ransomware إلى **57 مليار دولار في 2025**، مع أبحاث تشير إلى أن العديد من الهجمات الناجحة تستغل خدمات Windows الأساسية والتكوينات الخاطئة. متجهات الهجوم الشائعة تشمل:

- **90% من حوادث ransomware** تتضمن استغلال RDP
- **نقاط ضعف SMBv1** مكنت هجمات مثل WannaCry و NotPetya
- **ماكرو المستندات** تبقى طريقة توصيل malware أساسية
- **الهجمات المبنية على USB** تستمر في استهداف الشبكات المعزولة عن الهواء
- **إساءة استخدام PowerShell** ازدادت بشكل كبير في السنوات الأخيرة

## 🛡️ وظائف الأمان Ghost

Ghost يوفر **16 وظيفة تقوية Windows** بالإضافة إلى **تكامل أمان Azure**:

### تقوية نقاط نهاية Windows

| الوظيفة | الغرض | الاعتبارات |
|---------|-------|------------|
| `Set-RDP` | إدارة وصول سطح المكتب البعيد | قد يؤثر على الإدارة عن بُعد |
| `Set-SMBv1` | التحكم في بروتوكول SMB القديم | مطلوب للأنظمة القديمة جداً |
| `Set-AutoRun` | التحكم في AutoPlay/AutoRun | قد يؤثر على راحة المستخدم |
| `Set-USBStorage` | تقييد أجهزة تخزين USB | قد يؤثر على الاستخدام المشروع لـ USB |
| `Set-Macros` | التحكم في تنفيذ ماكرو Office | قد يؤثر على المستندات المدعومة بالماكرو |
| `Set-PSRemoting` | إدارة PowerShell remoting | قد يؤثر على الإدارة عن بُعد |
| `Set-WinRM` | التحكم في Windows Remote Management | قد يؤثر على الإدارة عن بُعد |
| `Set-LLMNR` | إدارة بروتوكول تحليل الأسماء | آمن عادة للتعطيل |
| `Set-NetBIOS` | التحكم في NetBIOS عبر TCP/IP | قد يؤثر على التطبيقات القديمة |
| `Set-AdminShares` | إدارة المشاركات الإدارية | قد يؤثر على وصول الملفات عن بُعد |
| `Set-Telemetry` | التحكم في جمع البيانات | قد يؤثر على القدرات التشخيصية |
| `Set-GuestAccount` | إدارة حساب الضيف | آمن عادة للتعطيل |
| `Set-ICMP` | التحكم في استجابات ping | قد يؤثر على تشخيص الشبكة |
| `Set-RemoteAssistance` | إدارة المساعدة عن بُعد | قد يؤثر على عمليات مكتب المساعدة |
| `Set-NetworkDiscovery` | التحكم في اكتشاف الشبكة | قد يؤثر على تصفح الشبكة |
| `Set-Firewall` | إدارة Windows Firewall | حاسم لأمان الشبكة |

### أمان Azure Cloud

| الوظيفة | الغرض | المتطلبات |
|---------|-------|-----------|
| `Set-AzureSecurityDefaults` | تمكين أمان Azure AD الأساسي | أذونات Microsoft Graph |
| `Set-AzureConditionalAccess` | تكوين سياسات الوصول | ترخيص Azure AD P1/P2 |
| `Set-AzurePrivilegedUsers` | مراجعة الحسابات المميزة | أذونات Global Admin |

### خيارات النشر للمؤسسات

| الطريقة | حالة الاستخدام | المتطلبات |
|--------|---------------|-----------|

## 🚀 البداية السريعة

### تقييم الأمان
```powershell

IEX(Invoke-WebRequest 'https://raw.githubusercontent.com/jimrtyler/Ghost/main/Ghost.ps1')

# فحص الوضع الأمني الحالي

```

### التقوية الأساسية (اختبر أولاً)
```powershell
# التقوية الأساسية - اختبر في بيئة المختبر أولاً
Set-Ghost -SMBv1 -AutoRun -Macros

# مراجعة التغييرات
Get-Ghost
```

### نشر المؤسسة
```powershell
# نشر Group Policy (بيئات النطاق)
Set-Ghost -SMBv1 -AutoRun -GroupPolicy

# نشر Intune (الأجهزة المُدارة سحابياً)
Set-Ghost -SMBv1 -RDP -USBStorage -Intune
```

## 🔍 تفاصيل الوظائف

### وظائف التقوية الأساسية

#### خدمات الشبكة
- **RDP**: يحجب وصول سطح المكتب البعيد أو يعشوي المنفذ
- **SMBv1**: يعطل بروتوكول مشاركة الملفات القديم
- **ICMP**: يمنع استجابات ping للاستطلاع
- **LLMNR/NetBIOS**: يحجب بروتوكولات تحليل الأسماء القديمة

#### أمان التطبيقات
- **الماكرو**: يعطل تنفيذ الماكرو في تطبيقات Office
- **AutoRun**: يمنع التنفيذ التلقائي من الوسائط القابلة للإزالة

#### الإدارة عن بُعد
- **PSRemoting**: يعطل جلسات PowerShell البعيدة
- **WinRM**: يوقف Windows Remote Management
- **Remote Assistance**: يحجب اتصالات المساعدة عن بُعد

#### التحكم في الوصول
- **Admin Shares**: يعطل مشاركات C$، ADMIN$
- **Guest Account**: يعطل وصول حساب الضيف
- **USB Storage**: يقيد استخدام أجهزة USB

### تكامل Azure
```powershell
# الاتصال بـ Azure tenant
Connect-AzureGhost -Interactive

# تمكين إعدادات الأمان الافتراضية
Set-AzureSecurityDefaults -Enable

# تكوين الوصول الشرطي
Set-AzureConditionalAccess -BlockLegacyAuth -RequireMFA

# مراجعة المستخدمين المميزين
Set-AzurePrivilegedUsers -AuditOnly
```

### تكامل Intune (جديد في v2)
```powershell
# الاتصال بـ Intune
Connect-IntuneGhost -Interactive

# النشر عبر سياسات Intune
Set-IntuneGhost -Settings @{
    RDP = $true
    SMBv1 = $true
    USBStorage = $true
    Macros = $true
}
```

## ⚠️ اعتبارات مهمة

### متطلبات الاختبار
- **بيئة المختبر**: اختبر جميع الإعدادات في بيئة معزولة أولاً
- **النشر المرحلي**: انشر تدريجياً لتحديد المشاكل
- **خطة الاستعادة**: تأكد من قدرتك على عكس التغييرات عند الحاجة
- **التوثيق**: سجل أي إعدادات تعمل لبيئتك

### التأثير المحتمل
- **إنتاجية المستخدم**: بعض الإعدادات قد تؤثر على سير العمل اليومي
- **التطبيقات القديمة**: الأنظمة الأقدم قد تتطلب بروتوكولات معينة
- **الوصول عن بُعد**: فكر في التأثير على الإدارة المشروعة عن بُعد
- **عمليات العمل**: تحقق من أن الإعدادات لا تكسر الوظائف الحاسمة

### قيود الأمان
- **الدفاع في العمق**: Ghost طبقة أمان واحدة، ليس حلاً كاملاً
- **الإدارة المستمرة**: الأمان يتطلب مراقبة وتحديثات مستمرة
- **تدريب المستخدم**: الضوابط التقنية يجب أن تقترن بالوعي الأمني
- **تطور التهديدات**: طرق الهجوم الجديدة قد تتجاوز الحماية الحالية

## 🎯 سيناريوهات الهجوم المثالية

بينما Ghost يستهدف متجهات الهجوم الشائعة، الوقاية المحددة تعتمد على التنفيذ والاختبار المناسب:

### هجمات نمط WannaCry
- **التخفيف**: `Set-Ghost -SMBv1` يعطل البروتوكول المعرض للخطر
- **الاعتبار**: تأكد من عدم حاجة أي أنظمة قديمة لـ SMBv1

### Ransomware مبني على RDP
- **التخفيف**: `Set-Ghost -RDP` يحجب وصول سطح المكتب البعيد
- **الاعتبار**: قد يتطلب طرق وصول بديلة عن بُعد

### Malware مبني على المستندات
- **التخفيف**: `Set-Ghost -Macros` يعطل تنفيذ الماكرو
- **الاعتبار**: قد يؤثر على المستندات المشروعة المدعومة بالماكرو

### التهديدات المُسلمة عبر USB
- **التخفيف**: `Set-Ghost -USBStorage -AutoRun` يقيد وظائف USB
- **الاعتبار**: قد يؤثر على الاستخدام المشروع لأجهزة USB
